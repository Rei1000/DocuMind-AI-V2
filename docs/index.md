# DocuMind-AI

AI-gestütztes Dokumenten- und Wissensanalysesystem.

DocuMind-AI ermöglicht die semantische Analyse und intelligente Suche in Unternehmensdokumenten.  
Das System kombiniert Retrieval-Augmented Generation (RAG), Vector Search und Large Language Models.

---

## Architektur

Frontend  
Next.js

Backend  
FastAPI

AI Layer

- Retrieval-Augmented Generation (RAG)
- Vector Database (Qdrant)
- Machine Learning Ranking
- Large Language Models

Deployment

Docker
